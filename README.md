💻 Installation
1. Clone the repository
git clone https://github.com/hetvisenghani12-commits/Student_Task_Manager.git
2. Open the project
cd Student_Task_Manager
3. Install dependencies
npm install
4. Start the Expo development server
npm start

You can then:

Press w to open the web version
Press a to run on Android
Scan the QR code using Expo Go on your mobile device
🔥 Firebase

The project uses Firebase for application-related services.

Before running the project with your own Firebase project, configure the Firebase settings in:

firebase.js
